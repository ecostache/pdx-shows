# PDX Shows

An independent guide to upcoming concerts and live music in Portland, Oregon.

Browse shows by date or venue at [PDX Shows](https://pdxshows.com).

## About

PDX Shows brings Portland's live-music calendar into one simple, searchable place. Listings focus on upcoming music events at local venues.

## Run locally

Requires Node.js 24 LTS and pnpm 11.23.0.

```sh
nvm use
corepack enable
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
